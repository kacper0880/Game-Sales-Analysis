# 🎮 Video Game Sales Dashboard (Tableau)

## 📌 Project Overview
This project analyses global video game sales data to uncover trends in regional performance and genre popularity. An interactive dashboard was built in Tableau to explore how different regions contribute to total sales and which game genres perform best across markets.

The dataset is sourced from VGChartz (via Zenodo) and contains historical sales data for video games that have sold more than 100,000 copies worldwide.

This project was completed to practice data analysis, data visualisation, and presentation skills.

---

## 🎯 Objectives
- Analyse global video game sales by region.
- Identify top-performing genres within each region.
- Build an interactive Tableau dashboard for exploration and storytelling.
- Demonstrate data preparation, visual design, and dashboard interactivity.

---

## 📊 Key Features
- **Regional Sales Breakdown:** Pie chart showing the percentage contribution of each region (Europe, North America, Japan, Other).
- **Interactive Tooltips:** Hovering over a region displays the top 3 selling genres for that region.
- **Filters:** Year filter allows users to explore changes over time.
- **Visual Enhancements:** Genre icons, formatted labels, and clean layout for clarity and usability.

---

## 🛠 Tools Used
- **Tableau** – Dashboard creation and interactivity  
- **CSV Dataset (Zenodo / VGChartz)** – Data source

---

## 📁 Dataset
**Source:** Zenodo – Video Game Sales Dataset (scraped from VGChartz)

The dataset includes:
- Game name  
- Platform  
- Year  
- Genre  
- Publisher  
- Regional sales (NA, EU, JP, Other)  
- Global sales  

> ⚠️ Note: The dataset primarily reflects physical retail sales and may not fully capture digital sales, especially in more recent years.

---

## 📈 Example Insights
- Different regions show distinct genre preferences (e.g., RPGs performing strongly in Japan, Action and Sports dominating Europe and North America).
- Regional market contributions vary significantly, highlighting the importance of localisation strategies.
- Long-term trends show shifts in genre popularity and platform performance over time.
